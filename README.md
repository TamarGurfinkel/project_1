ברוכים הבאים לפרויקט ניתוח נתונים במסגרת קורס "מבוא לניתוח נתונים"!  
בפרויקט זה נבחן את הקשר בין החזקת נשק חם לשיעורי אלימות קטלנית, כולל מקרי רצח והתאבדויות, תוך שימוש בנתונים היסטוריים מארה"ב.

## 📚 תיאור הפרויקט

הפרויקט מבוסס על נתוני השנים 1949–2020, מתוך המאמר:  
**"State-level household gun ownership proxy dataset, 1949–2020" (Kang & Rasich, 2023)**.

1.	האם קיים קשר בין שיעור הזמינות של כלי נשק חם (כפי שנמדד ע״י מדד הFSS ) לבין שיעורי הרצח הכלליים בארה״ב לאורך השנים ?
2.	האם קיימת השפעה של  זמינות כלי הנשק (הנמדדת ע״י מדד הFSS ) על שיעורי ההתאבדות באזורים הגיאוגרפים השונים וכן לאורך השנים ?
   3.	3.	האם קיימים פערים בין האזורים השונים בארצות הברית מבחינת שיעורי הרצח ורמת הבטיחות האישית?
